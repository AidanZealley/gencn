Install a block with `npx shadcn add @gencn/<name>-block`. Blocks are published for Base UI (`base-*`) and Radix (`radix-*`, `new-york`, `default`) styles. Slider and Select use Base UI's APIs, so they're Base UI only, and React Aria styles aren't published yet.
